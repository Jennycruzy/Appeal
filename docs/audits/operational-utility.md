# Operational utility measurement audit

Recorded: 2026-08-31

The reproducible measurement is generated by:

```text
make measure-operational-utility
```

and written to
[`evidence/operational-utility-measurement.json`](../../evidence/operational-utility-measurement.json).
It runs six deterministic, aggregate-only scenarios: a clean win, injection
quarantine, missing-evidence abstention, evidence-arrival wake, deadline
abandonment, and level-two escalation. The scenarios exercise the same local
state machine, event handlers, session store, receipt ledger, and mutation
journal used by the restart proof.

The report records transitions, autonomous transitions, human actions, elapsed
workflow hours, external mutation count, final state, and case fingerprint for
each scenario. It also records the number of cases that refused to file when
the input was unsafe, unsupported, or expired. The current deterministic run
contains six synthetic cases, 47 transitions, 44 autonomous transitions, 3
human actions, and 3 synthetic mutation representations. Those are workflow
operations, not clinical outcomes or production throughput.

## External reference context

For context only, the report derives an administrative-burden benchmark from
the [AMA 2025 prior-authorization survey](https://www.ama-assn.org/about/leadership/latest-prior-authorization-survey-shows-promised-reform-remains-elusive)
(about 40 requests and 13 hours per physician per week) and a wage reference
from the [BLS May 2024 occupational-wage archive](https://www.bls.gov/news.release/archives/ocwage_04022025.htm)
(medical-secretary median hourly wage $21.46). The derived $6.9745 per request
is a published-benchmark sensitivity, not measured Appeal labor saved.

The report also reads the accepted Oregon external-review aggregate and records
585 overturned-or-partial outcomes out of 1,640 completed reviews (0.356707).
This is explicitly an external-review outcome proxy, not a prior-authorization
overturn rate and not a comparison against Appeal predictions. CMS QIC records
are likewise regulator-authored summaries without the complete clinical
Evidence Floor.

## Dollar claim boundary

No allowed medical amount is present in the accepted sources, so
`per_abandoned_appeal_usd` is intentionally `null`. If an authorized amount is
later supplied, the report's sensitivity formula is:

```text
authorized_allowed_amount_usd * real_outcome_proxy.overturn_proxy_rate
```

That calculation must remain labeled as sensitivity until a complete
de-identified Appeal corpus, a predeclared evaluation protocol, and a valid
case-level economic baseline exist. The measurement therefore demonstrates
operational behavior and honest controls without turning synthetic success or
an external proxy into a clinical efficacy claim.
